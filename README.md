\# RPA-BASICS



UiPath RPA fundamentals — daily practice workflows built as part of PEP.



\## Day-1

Core variable, Assign-activity, and workflow-argument exercises:

\- Assign.1: Display a greeting using a string variable

\- Assign.2: Add two numbers using Assign

\- Assign.3: Subtract two numbers using Assign

\- Assign.4: Multiply two numbers using Assign

\- Assign.5: Concatenate two words into a greeting

\- Assign.6: Build a full name from first and last name

\- Assign.7: Take user input via Input Dialog and display it

\- Assign.8: Pass a number from a main workflow to a sub-workflow via an In argument

\- Assign.9: Pass a name from a main workflow to a sub-workflow via an In argument

\- Assign.10: Employee salary calculation across Main.xaml and CalculateSalary.xaml using In/Out arguments
